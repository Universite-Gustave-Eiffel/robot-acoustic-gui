class main_controller.MainController[source]

Bases : QObject

Chef d’orchestre de l’application.

Cette classe centrale gère la logique métier et sert de pont entre l’interface graphique (GUI) et les modules de bas niveau (robot, PULSE). Elle ne contient aucune logique d’interface utilisateur mais communique avec elle via le système de signaux et slots de Qt.

Variables:

  • robot – Instance du contrôleur de robot (RobotController).

  • pulse – Instance du driver PULSE (PulseLabshopDriver).

  • point_manager – Instance du gestionnaire de listes de points (PointManager).

  • sequence_thread – Thread qui exécute la séquence de mesure.

class controller_interface.GalilDriver.GalilDriver(port, baudrate, timeout)[source]

Bases : object

Gère la communication de bas niveau avec le contrôleur Galil via une liaison série.

Cette classe est responsable de l’établissement de la connexion, de l’envoi de commandes textuelles brutes, et de la lecture des réponses. Elle n’a aucune connaissance de la cinématique du robot ou de la signification des axes.

Paramètres:

  • port – Le nom du port série (ex: “COM7”).

  • baudrate – Le débit en bauds (ex: 38400).

  • timeout – Le timeout pour les lectures sur le port série, en secondes.

connect()[source]

Établit la connexion avec le contrôleur sur le port série.

Tente d’ouvrir le port, vérifie la présence du prompt Galil (“:”), et désactive l’écho des commandes pour simplifier la communication.

Renvoie:

True si la connexion est établie avec succès, False sinon.

disconnect()[source]

Ferme la connexion série avec le contrôleur.

send_query(command, retries=2)[source]

Envoie une commande « query » (qui retourne une valeur) et parse la réponse.

Cette méthode est plus robuste que send_cmd() pour les requêtes qui doivent retourner une valeur. Elle gère les tentatives multiples et nettoie la réponse pour ne retourner que la valeur utile.

Paramètres:

  • retries – Le nombre de tentatives en cas de réponse invalide.

Renvoie:

La valeur retournée par le contrôleur, ou None en cas d’échec.

class controller_interface.GalilDriver.RobotController(driver, config)[source]

Bases : object

Contrôleur de haut niveau pour le robot acoustique.

Cette classe utilise un GalilDriver pour communiquer avec le matériel. Elle implémente la logique de haut niveau, y compris : - La conversion entre unités physiques (mm, degrés) et pas moteur. - La cinématique directe et inverse pour gérer les coordonnées « capsule ». - Les commandes de mouvement complexes (absolu, relatif, parking). - La gestion du mode « jog » pour le contrôle manuel.

Paramètres:

  • driver (GalilDriver) – Une instance de GalilDriver configurée.

  • config (ConfigParser) – Une instance de configparser.ConfigParser contenant les sections [RATIOS], [OFFSETS], etc.

Fenêtre de contrôle manuel avancé du robot.

Cette fenêtre offre des fonctionnalités de pilotage direct du robot, indépendamment du séquenceur de la fenêtre principale. Elle est essentielle pour les phases de calibration, de test et de positionnement initial.

Elle propose deux modes de déplacement : - Pas-à-pas : Mouvements relatifs d’une distance fixe. - Temps réel : Mouvements continus (jog) contrôlés au clavier.

Elle permet également de définir les positions de référence (Zéro, Parking) et d’ajouter la position actuelle à la liste de points de la fenêtre principale.

class gui.log_viewer_window.LogViewerWindow(file_path, title, icon_name_or_path=None, parent=None)[source]

Fenêtre de visualisation de logs en temps réel.

Cette visionneuse est conçue pour « suivre » un fichier de log (comme la commande tail -f sous Linux). Elle lit les nouvelles lignes ajoutées au fichier à intervalle régulier et les affiche.

Fonctionnalités : - Rafraîchissement automatique. - Filtrage par niveau de log (DEBUG, INFO, WARNING, etc.). - Défilement automatique optionnel. - Limitation du nombre de lignes affichées pour maintenir la fluidité de l’interface, sans altérer le fichier de log complet sur le disque.

  • icon_name_or_path (Optional[str]) – Chemin vers l’icône de la fenêtre.
